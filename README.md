### 감정 일기장 (Emotion Diary)

**React를 활용한 개인 프로젝트**  
감정과 일상을 기록할 수 있는 간단하고 직관적인 **감정 일기장**을 개발했습니다. 이 프로젝트는 React의 주요 기능과 상태 관리 개념을 익히고, 프론트엔드 개발 능력을 실무에 가깝게 적용하기 위해 진행한 개인 프로젝트입니다.  

---

#### 🛠️ 사용 기술  
- **Frontend**:  
  - **React**: 컴포넌트 기반의 효율적인 UI 설계  
  - **JavaScript (ES6+)**: 동적인 기능 구현  
  - **HTML & CSS**: 스타일링 및 레이아웃 구성  

---

#### ✨ 주요 기능  
1. **감정 선택**  
   - 사용자가 다양한 감정을 선택할 수 있는 감정 버튼 UI 제공  
   - 각 감정에 따라 시각적인 차별화 (아이콘 및 색상)  

2. **일기 작성**  
   - 사용자가 날짜, 감정, 그리고 내용을 기록 가능  
   - 작성된 데이터는 리스트 형태로 저장  

3. **일기 관리**  
   - 작성된 일기를 조회, 수정, 삭제할 수 있는 CRUD 기능 구현  

4. **상태 관리**  
   - React의 `useState` 및 `useEffect`를 활용하여 동적인 데이터 관리  

---

#### 📚 프로젝트에서 배운 점  
1. **React의 기본 개념 이해**  
   - 컴포넌트와 상태 관리의 구조를 체계적으로 설계  
   - Props와 State를 활용하여 데이터의 흐름 관리  

2. **동적 UI 개발**  
   - 조건부 렌더링을 통해 사용자 경험(UX)을 향상  

3. **코드 재사용성**  
   - 재사용 가능한 컴포넌트를 설계하여 유지보수성을 향상
